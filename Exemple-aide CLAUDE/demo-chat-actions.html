💬 Chat : réactions, réponses, modifier, supprimer

Les 3 versions font la même chose, seule la façon d'ouvrir les actions change. Réactions : 👍 😂 😮 😢 🔥 ❤️ (une par personne, re-cliquer l'enlève). Modifier / supprimer : seulement ses propres messages. Un message supprimé laisse « Message supprimé ». Les bulles « … » s'affichent quand quelqu'un écrit (clique « Simuler » à droite).
